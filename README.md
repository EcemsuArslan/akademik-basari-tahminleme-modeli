# Akademik Basari Tahminleme Modeli-
Üniversite öğrenci verilerini kullanarak, akademik başarısızlık riskini önceden tespit eden bir risk skorlama modeli geliştirilmiştir. Pandas ve Scikit-Learn kütüphaneleri kullanılarak veri temizleme, özellik mühendisliği ve sınıflandırma algoritmaları ile tahminleme doğruluğu maksimize edilmiştir.
